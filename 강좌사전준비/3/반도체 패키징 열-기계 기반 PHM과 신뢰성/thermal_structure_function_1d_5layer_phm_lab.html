그림 1. 5층 패키지 개념도

1D 수직 열경로
열원에서 주변까지 열이 지나가는 순서대로 5개 층을 배치한 1D 모델이다. 각 층의 두께·열전도율·체적열용량으로부터 R = L/(kA), C = cvAL 를 계산한다. Layer 2(Die attach)가 본 실습의 열화 대상층이다.

그림 2. 1D Cauer 셀 분할 개념도

총 50단
각 물리층을 동일한 크기의 셀로 공간 분할하면 1D 열확산이 재현되어, 정답 누적 구조함수에서 층마다 하나의 선형 구간이 나타나고 층 경계에서 기울기가 바뀐다. 셀 하나의 값은 Rcell = Rlayer/N, Ccell = Clayer/N 이다.

층별 물성 및 계산된 열저항·열용량

A = 10 mm × 10 mm = 1.0×10⁻⁴ m²
열화 모델. 열용량과 형상은 그대로 두고 대상 층의 유효 열전도율만 k → k / 열화배율로 낮춘다. 따라서 해당 층의 R만 배율만큼 증가하고 C는 변하지 않는다.

그래프 1. 과도 온도 응답 Tj(t)

t = 0 에서 전력 P를 인가한 step heating 응답이다. 로그 시간축에서 각 층의 열용량이 순차적으로 채워지며 계단 형태가 나타난다.

그래프 2. 열임피던스 Zth(t)

Zth(t) = [ Tj(t) − T0 ] / P  [K/W],  Zth(∞) → Σ Ri
온도 응답을 전력으로 정규화한 값이다. 정상상태 값이 곧 총 열저항이 된다.

그래프 3. 열임피던스 차이 ΔZth(t)

열화 곡선에서 정상 곡선을 뺀 값이다. 차이가 커지기 시작하는 시각이 열화가 위치한 층의 열확산 시간과 관련된다.

수치 요약

Zth(t) = [Tj(t) − T0] / P 로 정규화하므로 구조함수는 입력전력 P 와 주변온도 T0 에 무관하다. 다만 온도 잡음 σ 는 절대값이라 P 가 작으면 SNR 이 나빠져 역추정 정확도만 떨어진다. Zth(∞)와 이론 ΣR의 차이는 유한한 측정시간과 수치적분 오차에서 비롯된다.
왜 로그 시간 미분인가. 열확산은 시간상수가 수십~수억 배 차이 나는 다중 스케일 현상이므로 z = ln(t) 축에서 다룬다. 로그 시간 미분 h(z) = dZth/d ln t 는 시간상수 스펙트럼과 커널 w(z) = exp(z − ez) 의 합성곱이 되어, 디컨볼루션으로 스펙트럼을 복원할 수 있다.
Zth(t) = Σ Ri [1 − exp(−t/τi)]  ⇒  dZth/d ln t = Σ Ri (t/τi) exp(−t/τi)
minimize over r ≥ 0 :  ‖ K r − h ‖² + λ² ‖ L r ‖²  (L = 2차 차분 행렬, FISTA 비음수 투영)

그래프 4. 로그 시간 미분 dZth/d ln(t)

국소 다항식(Savitzky–Golay 등가) 평활 후 중앙차분으로 계산한다. 평활 창을 키우면 잡음은 줄지만 인접한 시간상수 피크가 뭉개진다.

그래프 5. 시간상수 스펙트럼 (시함수)

각 막대는 해당 로그 시간상수 구간이 담당하는 Foster 열저항 성분 Ri [K/W]이다. λ가 작으면 뾰족하지만 잡음에 취약하고, 크면 매끄럽지만 피크가 병합된다.

디컨볼루션 적합도

복원된 스펙트럼을 커널과 다시 합성한 결과와 측정 로그미분의 비교이다. 회색 영역은 신호가 잡음 수준보다 작아 시간상수 추정에서 제외한 구간이다.

스펙트럼 요약

측정 시간창(tmin~tmax) 밖의 시간상수는 원리적으로 식별되지 않으므로 해석에서 제외해야 한다.

그림 3. Foster와 Cauer 차이 개념도

동일 임피던스, 다른 구조
두 회로는 열원에서 본 임피던스가 완전히 같지만 내부 구조가 다르다. Foster의 각 RC 성분은 실제 패키지 층과 일대일로 대응하지 않으며, Cauer 사다리만이 열원에서 주변으로 이어지는 순차적 열경로를 나타낸다.
ZF(s) = Σ RF,i / (1 + s τF,i) = N(s)/D(s)  →  연분수 전개  Y = D/N = sC₁ + 1/(R₁ + 1/(sC₂ + …))

그래프 6. Zth와 Foster 재구성 ZF

축약된 Foster 모델이 원래 열임피던스를 얼마나 재현하는지 확인한다. 차수가 너무 낮으면 재현이 나빠지고, 너무 높으면 Foster–Cauer 변환이 수치적으로 불안정해진다.

그래프 7. Foster 모델 재구성 잔차

잔차가 특정 시간대에 몰려 있으면 그 시간상수 영역의 표현이 부족하다는 뜻이다.

Foster 파라미터 (정상 / 열화)

Cauer 파라미터 (연분수 전개 결과)

해석 주의. Cauer 단수의 R, C는 물리 층과 정확히 일치하는 것이 아니라 열원에서 본 유효 열경로의 순차적 분해이다. 누적값을 이어 그린 것이 곧 역추정 구조함수이다.

그림 4 · 그래프 8. 누적 구조함수 CΣ(RΣ)

배경 밴드는 정답 모델의 5개 층 구간이다. 곡선이 완만하면(기울기 큼) 열저항은 작고 열용량이 큰 재료, 가파르면 열저항이 큰 계면층이다. 정답 곡선은 실선, 역추정 곡선은 점선·기호로 구분된다.

그림 5. 정상 vs 열화 비교 설명도

개념도
열화가 발생한 층에서는 열용량이 거의 그대로인 채 열저항만 늘어나므로, 그 구간에서 곡선이 오른쪽으로 늘어나고 이후 층 전체가 통째로 오른쪽으로 평행 이동한다.

그림 6 · 그래프 9. 미분 구조함수 K(RΣ) = dCΣ/dRΣ

각 층은 K ≈ Ci/Ri 높이의 plateau로 나타난다. 열화된 층은 plateau 높이가 낮아지고 폭(열저항 구간)이 넓어진다.

그래프 10. 구조함수 수평 이동 ΔRΣ(CΣ)

동일 누적 열용량 위치에서 두 구조함수의 열저항 차이다. 이 값이 임계값을 연속으로 넘는 최초 위치를 분기점으로 정의한다.

교육용 해석 지침

  1. Foster 네트워크의 각 RC 성분은 실제 패키지 층과 일대일로 대응하지 않는다.
  2. Cauer 네트워크는 열원에서 주변으로 이어지는 순차적인 유효 열경로를 나타낸다.
  3. 구조함수에서 관찰되는 분기점은 반드시 기준 시편과 비교하여 해석해야 한다.
  4. 실제 패키지는 3차원 열확산과 병렬 열경로를 가지므로 1D 예제처럼 층 경계가 항상 완벽히 분리되지는 않는다.
  5. 미분 구조함수는 평활화와 정규화 조건에 민감하다.
  6. 본 예제는 알고리즘과 PHM 진단 원리를 이해하기 위한 교육용 1D 5층 모델이다.
  7. 본 실습의 핵심 고장 시나리오는 “heat source로부터 2번째 층(Die attach)의 열화”이다.
